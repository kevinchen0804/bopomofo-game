# 注音魔法屋

給 5 歲小朋友使用的單頁注音學習遊戲，採紫粉黏土花園風格，主要針對 iPad 觸控操作設計。

開啟網站會先進入遊戲主頁，可從三張大卡片選擇玩法；遊戲內的房子按鈕可以隨時回到主頁，答題進度與靜音狀態會保留。

## 玩法

- 聽音選字：每回合 10 題；答對後會自動進入並播放下一題。第一次答對會得到黃色星星，答錯過的題目維持灰色星星。
- 注音小卡：37 個注音符號，只顯示並朗讀注音，不附範例。
- 小卡魔法版：保留詞語、拼音、分類與五種聲調練習。
- 庫洛米與美樂蒂固定在左右兩側，並有輕微不同步浮動動畫。

## iPad 語音

遊戲使用 Safari 內建語音，優先選擇中文（台灣）聲音，並相容新版與較舊版 iPad 的聲音載入方式。若沒有聲音，請先調高裝置音量，再到「設定 → 輔助使用 → 閱讀與朗讀」；較舊版本可能顯示為「朗讀內容」。

## 放到 GitHub Pages

1. 將 `index.html` 與整個 `assets` 資料夾上傳到 GitHub repository 根目錄。
2. 到 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` 與 `/ (root)`，再按 **Save**。

本機預覽時，請用 HTTP 伺服器開啟；直接點兩下 `index.html` 也能顯示，但部分瀏覽器的語音策略可能不同。
